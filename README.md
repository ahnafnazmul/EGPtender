## এই ভার্সনে যা আছে
- প্রতি ৪ ঘণ্টায় eprocure.gov.bd এর লিস্ট পেজ স্ক্যান করে
- নতুন টেন্ডার পেলে Telegram এ **সম্পূর্ণ বাংলা** ফরম্যাটে মেসেজ পাঠায়:
  - সিরিয়াল নম্বর, টেন্ডার আইডি, টাইটেল, অর্গানাইজেশন, প্রচারের তারিখ, শেষ হবার তারিখ
  - টেন্ডার শিডিউল দাম ও টেন্ডার সিকিউরিটি (ডিটেইলস পেজ থেকে বের করা)
- PDF ডাউনলোড/সংযুক্তির অংশ সম্পূর্ণ বাদ দেওয়া হয়েছে (সরলীকরণের জন্য)
- সাইট সাময়িকভাবে সাড়া না দিলে বট নিজে থেকে ৩ বার চেষ্টা করে

## ইনস্টল করার সবচেয়ে নিরাপদ পদ্ধতি — Upload Files দিয়ে

বারবার copy-paste এ ভুল হচ্ছিল, তাই এবার এই জিপের ফাইলগুলো **সরাসরি drag & drop
করে আপলোড করুন**, ম্যানুয়ালি কিছু টাইপ/পেস্ট করার দরকার নেই:

1. আপনার repo-র মূল পেজে যান (root, কোনো ফোল্ডারের ভেতরে না)।
2. **Add file → Upload files** ক্লিক করুন।
3. এই জিপ থেকে বের করা সব ফাইল/ফোল্ডার (`scraper.py`, `requirements.txt`,
   `state.json`, `README.md`, `.github/workflows/main.yml`) একসাথে ড্র্যাগ
   করে ড্রপ করুন। ব্রাউজার ফোল্ডার-সহ আপলোড সাপোর্ট করে, তাই পুরো ফোল্ডারই
   টেনে আনতে পারেন।
4. একই নামের ফাইল আগে থেকে থাকলে GitHub এমনিতেই সেগুলো ওভাররাইট করবে।
5. নিচে "Commit changes" বাটনে ক্লিক করুন।

**আপলোডের পর যাচাই করুন:** repo-তে গিয়ে দেখুন যে **শুধু একটাই** workflow
ফাইল আছে (`.github/workflows/main.yml`) — যদি পুরনো `scan.yml` নামে
আরেকটা ফাইল থেকে যায়, সেটা ডিলিট করে দিন (দুটো workflow একসাথে থাকলে
প্রতি রানে ডাবল মেসেজ যাবে)।

## Secrets (যদি আগে না দিয়ে থাকেন)
Settings → Secrets and variables → Actions:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

## রান করা
Actions ট্যাব → "eGP Tender Scanner" → **Run workflow** বাটনে ক্লিক করুন।

`state.json` খালি রাখা হয়েছে, তাই এই রানে বর্তমান লিস্টের সবগুলো টেন্ডারই
"নতুন" হিসেবে ধরে সবার জন্য টেলিগ্রামে মেসেজ পাঠাবে — এটাই এখন কাঙ্ক্ষিত,
কারণ এতে পুরো ফরম্যাট একসাথে যাচাই করা যাবে।

## যদি আবারও "০ রো" আসে
`DEBUG_MODE: "true"` রাখা আছে, তাই রান শেষে **debug-output** আর্টিফ্যাক্ট
থেকে zip ডাউনলোড করুন — এতে থাকবে:
- `debug_screenshot_attempt1/2/3.png` — প্রতিটা চেষ্টার স্ক্রিনশট
- `debug_page_attempt1/2/3.html` — প্রতিটা চেষ্টার HTML

স্ক্রিনশটে যদি স্বাভাবিক টেন্ডার লিস্ট না দেখে কোনো এরর/ক্যাপচা/খালি পেজ
দেখা যায়, তাহলে বুঝবো সাইট সাময়িকভাবে বট-রিকোয়েস্ট ব্লক করছে — সেক্ষেত্রে
কিছুক্ষণ (২০-৩০ মিনিট) অপেক্ষা করে আবার Run workflow দিলে সাধারণত ঠিক
হয়ে যায়।
